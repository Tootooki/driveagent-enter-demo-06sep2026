# DRIVE AGENT — ENTER DEMO

The white homepage contains one large centered ENTER DEMO button, which opens the PPC demo. The page fits the available screen without scrolling. The existing header, expanding category menu, Login preview and chat remain available.

The compact searchable Accounting menu and Chrome iOS viewport workaround are preserved. Earlier releases remain unchanged. This static demo makes no live Amazon changes.

Open the project root for the homepage, `demo.html?workspace=targets` for PPC, or `demo.html?workspace=accounting&menu=open` for Accounting.

Validation includes the existing unit checks, homepage/menu/chat integration checks, mobile and desktop viewport inspection, and the native demo navigation.

Publish committed files with `npm run publish`.
